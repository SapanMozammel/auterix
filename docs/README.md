# Auterix Documentation Hub

Welcome to the official Auterix documentation. Auterix is a deterministic, tool-neutral autonomous context protocol and multi-agent engineering workflow.

Whether you are an individual developer using Cursor and Claude Code or an agency deploying autonomous AI agents across client codebases, these guides provide copy-paste runbooks, architectural standards, and automated CI/CD guardrails.
