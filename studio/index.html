FREQUENTLY ASKED QUESTIONS

Developer Questions Answered

Straightforward answers about our open core, private repository, and privacy.

Why is Auterix split into a public repo and a private repo?
The core Auterix CLI engine, the universal context protocol, and the 6 vendor adapters (Cursor, Claude Code, Antigravity, Copilot, Codex, Augment) are 100% open-source under the MIT license on GitHub. The commercial Pro repository contains production-ready boilerplates, enterprise database security policies, automated CI GitHub Action bots, and local pre-commit guardrails. Keeping them separate ensures the core protocol remains community-owned while funding ongoing maintenance and new stack blueprints.
What deliverables do I receive immediately when I purchase Pro?
Immediately upon purchase on Gumroad, you get a direct download link to Auterix-Pro-Production-Suite.zip containing all 5 production starter stacks, runnable boilerplate code (Next.js 15, FastAPI, Node 22, Expo, AI Agent Pipeline), the pre-commit hook script, the GitHub Action PR compliance workflow, the offline desktop studio, and your commercial license. You also receive an invitation to the private GitHub repository for lifetime updates.
Does Auterix send my code, prompts, or API keys to external servers?
Never. Auterix has zero external telemetry, zero tracking scripts, and zero API calls to proprietary servers. The Web Studio generates configurations 100% client-side in your browser using JSZip, and the CLI runs entirely on your local machine using standard Node.js without network access.
Can I use the Free open-source version for commercial client projects?
Yes! The public Auterix CLI and baseline adapter configurations are licensed under the permissive MIT License. You may use them freely in personal, open-source, or commercial projects. The Pro license gives you full commercial rights to use and adapt our proprietary production boilerplates, security policies, and CI bots across your team or client apps.
Can I switch between Cursor, Claude Code, and Antigravity mid-project?
Yes, that is the primary reason Auterix was built! When you run Auterix, it compiles your single canonical architectural contract into native instructions for Cursor (.cursor/rules/workflow.mdc), Claude Code (CLAUDE.md), Google Antigravity (.agents/rules/workflow.md), GitHub Copilot (.github/copilot-instructions.md), Codex (AGENTS.md), and Augment. You can write inline code in Cursor, perform deep refactors in Claude Code CLI, and run multi-agent audits in Antigravity with zero context loss.
