# Auterix — VS Code, Cursor & Windsurf Extension

**Zero-Drift Multi-Agent Context Standard & Integrity Guardrail**

Auterix synchronizes architectural invariants, type rules, and task progression across **21 modern AI coding assistants** — including Cursor, Claude Code, Google Antigravity, Windsurf, GitHub Copilot, Devin, and Aider.

---

## ⚡ Features

* **Real-Time Telemetry:** Live status bar indicator displays `$(shield) Auterix: 21 Tools Synced` when repository rules match the cryptographic SHA-256 hash lock.
* **Instant Drift Alert:** If an AI model or contributor edits rules without updating the lock, the status bar turns orange (`$(alert) Auterix: Drift Detected`).
* **1-Click Adapter Sync:** Run `Auterix: Re-Sync All 21 AI Adapters` from the Command Palette (`Ctrl+Shift+P` / `Cmd+Shift+P`).
* **Cross-Agent Shared Memory:** Log architectural decisions and anti-patterns with `Auterix: Record Decision in Shared Memory` so all 21 AI assistants inherit your project context.
* **Database Schema Extractor:** Right-click any Drizzle, Prisma, or SQL file and select `Auterix: Extract Active Schema to AI Context` to generate token-compact schema prompts.

---

## 🚀 Quickstart

1. Open your project root in VS Code or Cursor.
2. Initialize Auterix in your terminal:
   ```bash
   npx auterix@latest
   ```
3. The Auterix status bar badge will immediately appear in the bottom right corner.
